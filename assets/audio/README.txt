Persona theme: color-your-night.mp3
The header player plays:

    assets/audio/color-your-night.mp3

To use another song, replace that file with one of the same name, or change MAIN in js/player.js.

private. A public GitHub Pages site can be taken down for hosting music you do not own.

Jianghu theme: a two-song playlist
The header player plays these in order, then loops back to the first:

    1. assets/audio/hien-thien-duyen.mp3   (Hien Thien Duyen)
    2. assets/audio/ba-ho-thuyet.mp3       (Ba Ho Thuyet, Vietsub)

Use the next and previous buttons to move between them. To change the songs, replace the files with ones of the same name,
or edit TRACKS at the top of js/jianghu/player.js (add a line to add a third song).

Only publish songs you have the right to. A public GitHub Pages site can be taken down for hosting music you do not own.
